PETSMART ENTREGAS — VERSIÓN 12 (CONFIRMACIÓN ANTES DE SUBIR FOTOS)

QUÉ CAMBIÓ
- Se retiró el botón de eliminación de las fotos guardadas.
- Se eliminó la dependencia del servicio Worker de borrado de Cloudinary. No necesitas desplegar Cloudflare Worker.
- Al pulsar "Guardar evidencia", la app presenta una confirmación antes de iniciar cualquier carga.
- La confirmación muestra el número del pedido, cantidad de fotos, miniaturas, nombres y tamaños de los archivos seleccionados.
- Los botones son "Volver a revisar" y "Sí, subir fotografías". Si se cancela, no se envía ningún archivo.
- El aviso recuerda que las fotos no se pueden borrar desde la app.
- Se conserva la cámara, la galería, el límite de 6 fotos por pedido, Firebase, Cloudinary y la agrupación por ventaGrupoId.
- Service worker actualizado a petsmart-entregas-v12.

PUBLICAR
1. Haz una copia de seguridad del repositorio petsmart-entregas.
2. Descomprime MiniAppPetSmart_GitHubPages_V12_CONFIRMACION.zip.
3. Sube todos los archivos directamente a la raíz de https://github.com/informespetsmart/petsmart-entregas, reemplazando los archivos anteriores.
4. No subas el ZIP como un solo archivo.
5. No subas ni configures CloudinaryDeleteWorker: esta versión ya no lo utiliza.
6. Después del commit, cierra la PWA en Android y vuelve a abrirla. Si conserva la versión anterior, recarga la web en Chrome para que el service worker v12 sustituya la caché.

SI NECESITAS ELIMINAR UNA FOTO MANUALMENTE
- Localiza el asset y elimínalo desde Cloudinary.
- Después elimina el registro de metadatos correspondiente en Firebase Realtime Database en entregasEvidencias/<orderKey>/<evidenceId>.
- Si solo eliminas el asset de Cloudinary, el registro de Firebase seguirá mostrando una referencia a una imagen que ya no existe.
- La app no tiene controles para borrar fotografías.

SEGURIDAD Y ALCANCE
- Se conserva el preset unsigned actual de Cloudinary. La confirmación reduce errores de selección, pero no vuelve privadas las imágenes.
- No se modificaron las reglas remotas de Firebase.
- No se publicaron cambios en GitHub y no se probaron cargas reales contra Firebase/Cloudinary ni en un Android físico.

VALIDACIONES LOCALES
- Sintaxis JavaScript (app.js, sw.js y firebase-config.js).
- Parseo básico HTML.
- JSON válido del manifiesto PWA.
- Recursos de precache presentes.
