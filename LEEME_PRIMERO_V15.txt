PETSMART ENTREGAS + SEGUIMIENTO — V15

Esta carpeta contiene los archivos que deben quedar directamente en la raíz del repositorio GitHub Pages petsmart-entregas.

CAMBIOS V15
- La pantalla principal del repartidor ahora muestra únicamente las entregas cuya fecha de entrega corresponde al día actual en hora de Perú (America/Lima).
- Las entregas de otras fechas y las que aún no tienen fecha coordinada quedan en la pestaña Historial.
- El panel de administración Seguimiento también separa Hoy e Historial.
- El botón “Crear seguimiento” se renombró a “Activar enlace”. Esta acción crea el enlace público de seguimiento para una venta existente; no registra ni duplica ventas. Si el enlace ya existe, se recupera para administrarlo.
- Se renovó el icono instalable con un camión de reparto azul y naranja, en alta resolución, y se actualizó el caché PWA a V15.
- Se conserva la URL de la página pública original del inventario: https://informespetsmart.github.io/InventarioPetSmart2026/?seguimiento=TOKEN . No se modificó el diseño de esa página.

PUBLICACIÓN
1. Descomprime el ZIP.
2. Sube el CONTENIDO de esta carpeta directamente a la raíz del repositorio petsmart-entregas, reemplazando los archivos anteriores. No subas la carpeta contenedora como subcarpeta.
3. Espera a que GitHub Pages termine de publicar.
4. En el Android, cierra la app anterior y abre la URL del miniapp en Chrome. Si el icono anterior sigue apareciendo, desinstala el acceso/app anterior y vuelve a instalar desde Chrome.

IMPORTANTE
- Esta entrega no cambia Firebase, Cloudinary, las reglas de seguridad ni las ventas del inventario.
- No se ha realizado una prueba de inicio de sesión contra Firebase ni una publicación en GitHub desde aquí. La validación realizada es estática del código y de los archivos del paquete.
