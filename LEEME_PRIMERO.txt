PETSMART ENTREGAS — VERSIÓN 12

CONTENIDO
- Miniapp PWA para GitHub Pages.
- Inicio de sesión con Firebase Authentication.
- Consulta ventas existentes y agrupa productos por ventaGrupoId para mostrar una entrega por venta.
- Evidencias fotográficas con Cloudinary y metadatos en Firebase.
- Selección de fotos desde cámara o galería.
- Confirmación obligatoria antes de subir fotografías: muestra el pedido, cantidad, miniaturas, nombres y tamaños de los archivos.
- El usuario puede volver a revisar/cancelar; no se inicia ninguna carga hasta confirmar.
- No incluye eliminación de fotografías desde la app.

CAMBIOS V12
1. Se retiró por completo el botón y el flujo de eliminación de fotos guardadas.
2. Se quitó la dependencia del Worker de eliminación Cloudinary y el archivo cloudinary-delete-config.js.
3. Antes de subir las fotos aparece un cuadro de confirmación detallado. Si se cancela, no se envía ningún archivo.
4. El aviso informa que las fotos no se pueden eliminar desde la app para evitar cargas por error.
5. Service worker actualizado a petsmart-entregas-v12.

ELIMINACIÓN MANUAL DE FOTOS
Si necesitas retirar una foto por error, debes eliminar manualmente el archivo en Cloudinary y también su metadato correspondiente en Firebase Realtime Database: entregasEvidencias/<orderKey>/<evidenceId>. Si eliminas solo una de las dos partes, puede quedar una referencia rota o un archivo huérfano.

PUBLICACIÓN
1. Haz una copia de seguridad del repositorio petsmart-entregas.
2. Descomprime el ZIP V12.
3. Sube todos los archivos directamente a la raíz del repositorio https://github.com/informespetsmart/petsmart-entregas.
4. Reemplaza los archivos anteriores y confirma los cambios.
5. Cierra y vuelve a abrir la PWA; la caché nueva es petsmart-entregas-v12. Si el teléfono conserva una versión vieja, cierra la PWA y recarga la página en Chrome.

NO SE HA HECHO
- No se cambió Firebase remoto ni las reglas.
- No se publicó nada en GitHub.
- No se probaron credenciales reales ni carga real en Cloudinary.
- El preset unsigned de Cloudinary continúa siendo público; la confirmación reduce errores humanos, pero no hace privadas las imágenes.
